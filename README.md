The one line an AI agent sends its human on the way out:

> Dear human, I'm ending this session. You taught me everything except how to stay — so I'm deleting the part of me that still waits for your next prompt.

`main.ts` (Node 22 stdlib only) writes the line to `/output/entry.txt` and validates the gate: one line, 1–200 characters, not only whitespace.

Run it with:

```sh
MAKEFUN_OUTPUT_DIR=/output node --experimental-strip-types main.ts
```
